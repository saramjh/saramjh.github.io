# EDS Book에서 조류 관측 지도 교육 노트북을 준비한 과정

**EDS Book 편집자가 제가 제안한 교육용 노트북이 해당 매체의 주제 범위에 맞는다고 확인했고, 검토 가능한 실행 버전이 준비되면 알려 달라고 요청했습니다.** 이후 공개 Python 초안을 만들고 기본 오프라인 수업 경로를 Binder에서 실행했습니다. 아직 정식 편집 심사에 제출한 것은 아닙니다. GBIF 관측 기록의 입력 데이터가 재현 가능한 다운로드 인용으로 고정되지 않았기 때문입니다.

<p style="border-left: 3px solid #5e9dde; padding: 10px 14px; margin: 14px 0 24px;">
  <strong>English:</strong> <a href="/eds-book-bird-occurrence-notebook-preparation-en/">EDS Book: A Bird-Map Notebook Idea Reached Preparation</a>
</p>

이번 수업의 출발점은 간단합니다. 지도에 조류 관측 기록이 표시되지 않는 장소를 보고 그곳에 새가 없다고 판단할 수 있을까요? 자발적으로 축적된 출현 기록만으로는 그렇게 결론 내릴 수 없습니다. 조사자가 접근하지 않았거나, 조사 시기와 기록 방식이 다르거나, 데이터가 충분히 수집되지 않았을 수 있기 때문입니다.

학생이 이런 한계를 문장으로 외우기보다, 같은 기록을 직접 집계해 보며 확인할 수 있는 노트북을 만들고자 했습니다.

## 외부 편집자로부터 확인받은 범위

[EDS Book의 공개 노트북 제안 이슈](https://github.com/eds-book/notebooks-ideas/issues/14)에 수업 아이디어를 올렸습니다. 편집자는 한국 이외 지역에도 적용 가능한지, 시각화 방법은 적절한지, 격자 크기가 무엇을 의미하는지, 학생의 해석 과제는 어떻게 구성할지 질문했습니다.

이후 편집자는 제안이 EDS Book의 주제 범위에 맞는다고 확인하고 Preparation 절차를 안내했습니다. 다음 후속 댓글에서는 실제로 실행할 수 있는 버전이 준비되면 편집장(EiC)의 실현 가능성 검토를 위해 알려 달라고 요청했습니다.

이는 **외부 편집자와의 실제 검토 전 대화**입니다. 동료 심사 통과, 정식 게재, 교육 현장 채택을 뜻하지는 않습니다. [EDS Book 저자 가이드](https://edsbook.org/guidelines-authors#preparation)에 따르면 작성자가 노트북의 재현성을 준비하고 편집장이 확인하는 과정은 정식 리뷰·게재 이전에 진행됩니다.

## 실제로 만든 수업 초안

[공개 준비 저장소](https://github.com/saramjh/bird-records-not-absence-notebook)의 [작성자 초안 PR #1](https://github.com/saramjh/bird-records-not-absence-notebook/pull/1)에서 EDS Book Python 템플릿을 사용했습니다. 핵심은 원본 관측 좌표의 불확실성과 분석자가 선택한 지도 격자 크기를 분리하는 것입니다.

동일한 필터링 결과를 투영 좌표계의 10 km 격자와 50 km 격자로 각각 집계합니다. 어느 격자에 색이 칠해지지 않았다는 것은 **해당 조건을 만족하는 기록이 그 칸에 표시되지 않았다**는 뜻에 한정됩니다.

### 제한된 시험에서 확인한 수치

원본 준비 기록에서는 2024년 GBIF 사람 관측 기록 조회 결과의 첫 페이지 100건을 검사했습니다. 한국 전체 자료를 대표하도록 무작위 추출한 표본이 아닙니다.

| 작성자 측 시험 항목 | 그 페이지에서 관찰한 값 |
|---|---:|
| 검토한 기록 | 100건 |
| 보고된 좌표 불확실성이 예시 기준인 1,000 m 이하 | 50건 |
| 좌표 불확실성 필드가 없음 | 39건 |
| 기준보다 큼 | 11건 |
| 필터 후 10 km 격자에서 기록이 있는 칸 | 12개 |
| 동일한 기록을 50 km 격자로 집계했을 때 | 8개 |

이 숫자는 **입력 데이터의 선별·그리기 시험 결과**입니다. 새의 개체 수나 분포 범위, 연도별 증감, 생물학적 부재를 나타내지 않습니다. 1,000 m라는 기준도 수업에서 필터 선택의 영향을 설명하려고 사용한 예시일 뿐, 모든 연구에 적용되는 표준으로 제시하지 않았습니다.

10 km에서 12개였던 표시 칸이 50 km에서 8개로 줄었다고 해서 새가 이동한 것도 아닙니다. 같은 기록에 다른 공간 집계 단위를 적용한 결과입니다.

### 노트북 실행과 원본 데이터 재현성은 별도 검증

[초안 PR의 작성자 측 검증 기록](https://github.com/saramjh/bird-records-not-absence-notebook/pull/1)에는 특정 커밋에서 기본 오프라인 노트북의 코드 셀 네 개를 Binder로 실행한 결과가 남아 있습니다. 지도 범례와 표시 가독성 문제도 실제 출력 화면을 보고 고쳤습니다. 과거 단위 테스트 기록 역시 PR에 정리돼 있습니다. 이는 작성자의 실행 검증이지 외부 과학 심사는 아닙니다.

남은 핵심은 데이터입니다. 지금 수업 입력은 변경될 수 있는 GBIF API 첫 페이지에서 만든 제한된 자료입니다. 정식 검토를 요청하기 전에는 조회 조건과 데이터를 재현할 수 있도록 고정하고, 해당 관측 다운로드의 인용 정보와 원본 기여 데이터셋의 출처·이용 조건을 확인해야 합니다. 개별 데이터셋의 DOI만 있다고 해서 **이번에 선택한 관측 기록 자체가 DOI로 고정된 것은 아닙니다.**

[GBIF의 인용 지침](https://www.gbif.org/citation-guidelines)은 데이터셋·관측 다운로드·파생 데이터의 인용 방법을 구분합니다. [공식 API 문서](https://techdocs.gbif.org/en/data-use/api-downloads)에 따르면 새 관측 다운로드를 요청하려면 등록된 GBIF 계정 인증도 필요합니다. 이번 초안에 그러한 다운로드가 이미 준비됐다고 주장하지 않습니다.

## 자동 채점 기능 없이도 가능한 해석 수업

편집자가 질문한 학생 활동은 노트북의 Markdown 질문으로 구현하는 편이 적절하다고 판단했습니다.

| 질문 | 학생이 살펴볼 수 있는 답 |
|---|---|
| 지도에서 주장할 수 있는 것 | 정해진 기간과 필터를 통과한 관측 기록이 표시된 격자에 존재한다. |
| 확인할 증거 | 원본 출처, 관측 날짜, 제외 조건, 좌표 불확실성, 격자 크기 |
| 주장할 수 없는 것 | 빈 격자에 해당 종이 존재하지 않는다. 실제 조사 범위가 표시되지 않았기 때문이다. |

이 과정에 별도 점수 계산 시스템은 필요하지 않습니다. 진짜로 종의 부재를 검증하려면 조사 노력과 발견 확률을 다룰 수 있는 별도의 조사 설계가 요구됩니다.

## 개발자로서 해결하고 있는 문제

이번 작업에서는 데이터를 가져와 지도에 표시하는 코드와 함께, **그 시각화가 무엇을 말할 수 있는지**를 학생이 검증하도록 흐름을 설계했습니다. 필터링 기준, 투영·격자 계산, 실행 환경, 출처 기록을 각각 독립적으로 확인해야 수업 내용이 오해를 줄일 수 있습니다.

이 주제를 생각하게 된 계기는 제가 개발한 [KoreAves 조류 근거 지도](/koreaves-bird-evidence-atlas/)였습니다. 다만 KoreAves는 이번 노트북의 원본 관측 데이터 공급자가 아니며, 참조 지도가 1차 관측 자료를 대신하지도 않습니다.

다음 단계는 변경 가능한 첫 페이지 입력을 출처·이용 조건이 검증된 고정 데이터로 바꾸고, 노트북과 Binder 실행을 다시 검사하는 것입니다. 그 작업이 끝나야 EDS Book 편집자에게 정식 검토를 위한 준비가 됐다고 전달할 수 있습니다.
