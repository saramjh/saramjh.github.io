**야키카레(焼きカレー)**는 밥과 카레에 치즈·달걀을 올려 오븐에 굽는 카레 요리입니다. 카레를 새로 만드는 과정 대신 **이미 준비된 카레 1인분**을 활용하므로, 남은 카레를 한 그릇 오븐요리로 바꾸고 싶을 때 참고할 만합니다.

제가 운영하는 Spoonie의 [야키카레 Recipe](https://spoonie.kr/recipes/545b0a52-76dc-491f-8198-7a0fef3bbef6?utm_source=devtestudinidae_blog&utm_medium=organic_editorial&utm_campaign=yaki_curry_20261014&utm_content=intro)는 **1인분·전체 조리 약 25분·재료 7가지**로 등록돼 있습니다.

## 주물팬과 달걀 익힘에서 중요한 점

원본에서는 **6인치 주물팬**에 밥을 깔고 *데운 카레*를 붓습니다. 소시지와 피망을 올린 다음 가운데를 살짝 파서 달걀을 깨 넣고, **모차렐라 치즈를 달걀 주변에 둘러** 굽습니다. 이렇게 하면 치즈의 색과 달걀의 익힘 상태를 확인하기 쉽습니다.

원본 굽기 온도는 **220℃**, 시간은 **10~12분**이며 치즈가 노릇하고 노른자는 반숙인 시점에 꺼냅니다. 실제 오븐마다 화력, 용기 두께가 다르므로 상태를 보면서 조절하세요. 달걀을 완전히 익혀 먹고 싶다면 충분히 익을 때까지 시간을 추가해야 합니다.

## 재료 7가지

| 재료 | 1인분 |
| --- | ---: |
| 밥 | 1공기 |
| 카레 | 1인분 |
| 소시지 | 3개 |
| 피망 | 1/2개 |
| 달걀 | 1개 |
| 모차렐라 치즈 | 60g |
| 파슬리 가루 | 1꼬집 |

이 레시피는 카레 자체의 재료와 만드는 과정을 포함하지 않습니다. 보관한 카레를 재사용할 때는 보관 상태를 확인하고 충분히 다시 데우세요.

## 정확한 6단계 조리 순서

1. 오븐을 **220℃로 예열**합니다.
2. 오븐용 6인치 주물팬에 밥을 깔고 미리 데운 카레를 붓습니다.
3. 소시지와 피망을 썰어 올린 뒤 가운데에 홈을 조금 만들어 달걀 1개를 깨 넣습니다.
4. 달걀 주변에 모차렐라 치즈 60g을 둘러 줍니다.
5. **220℃ 오븐에서 약 10~12분** 굽습니다. 치즈가 노릇하게 변하고 달걀이 원하는 만큼 익었는지 확인합니다.
6. 파슬리 가루를 뿌리고 팬째 내열 받침 위에 올립니다. **팬과 손잡이는 매우 뜨거우니** 보호 도구를 사용하세요.

## 자주 묻는 질문

**Q. 25분 동안 오븐에 구워야 하나요?**

아닙니다. **25분은 준비를 포함한 전체 조리 시간**입니다. 원본에서 오븐에 굽는 단계는 220℃에서 약 10~12분입니다.

**Q. 꼭 주물팬이어야 하나요?**

원본은 6인치 주물팬입니다. 오븐 사용이 허용되는 내열 용기로 바꿀 수 있지만, 넓이와 깊이가 달라지면 카레가 끓는 정도·달걀 익힘 시간이 변할 수 있습니다. **오븐 사용 가능 표시가 없는 팬은 넣지 마세요.**

**Q. 치즈를 달걀 위에 덮어도 되나요?**

원본은 달걀 주위에 둘러 굽습니다. 이 방법은 굽는 동안 노른자의 상태를 확인하기 쉽습니다. 완전히 덮으면 달걀 익힘 정도를 눈으로 확인하기 어렵습니다.

**Q. 소시지를 생략하면?**

재료나 식감은 달라지지만 이미 익힌 카레와 밥을 활용하는 기본 조리 흐름은 같습니다. 원본과 일치하는 분량을 원하면 소시지 3개를 사용하세요.
