# 부자 관상 테스트: AI로 나와 닮은 부자 찾기

![부자 관상 테스트 결과 화면](rich-face-test-preview.png)

[부자 관상 테스트 바로가기](https://saramjh.github.io/richChecker/)

## 프로젝트 개요

부자 관상 테스트는 업로드한 얼굴 사진을 AI로 분석해 포브스(Forbes) 2026 대한민국 부자 순위에 오른 인물 표본과 얼마나 닮았는지 비교해보는 웹 앱입니다.

이 테스트는 재산을 예측하거나 실제 관상을 판정하는 도구가 아니라, 얼굴 랜드마크를 이용해 "내 얼굴 특징이 어떤 표본과 가장 가까운가"를 가볍게 확인하는 엔터테인먼트 프로젝트입니다. 결과 화면에서는 가장 닮은 인물, 일치율, 6개 얼굴 항목별 분석, 재벌 유형 배지를 함께 보여줍니다.

## 새로 달라진 점

기존 버전은 성별을 먼저 선택하고 비교하는 흐름이었는데, 이번 버전은 성별 선택 없이 하나의 통합 표본으로 분석합니다. 사진을 올리면 브라우저 안에서 자동으로 얼굴을 찾고, MediaPipe Face Landmarker 기반의 얼굴 랜드마크를 사용해 특징 벡터를 계산합니다.

분석 결과도 단순히 "몇 퍼센트 닮았다"에서 끝나지 않게 바꿨습니다. 눈, 코, 입, 얼굴형 같은 주요 항목을 레이더 차트와 막대그래프로 나눠 보여주고, 각 항목에서 가장 가까운 인물도 함께 확인할 수 있습니다. 결과 이미지는 저장하거나 OS 공유 시트를 통해 공유할 수 있습니다.

## 개인정보와 이미지 처리

사진 분석은 사용자의 기기 안에서만 처리됩니다. 이 사이트는 정적 웹사이트라 업로드한 사진을 받을 서버가 없고, 얼굴 분석 모델과 비교 데이터도 브라우저에서 실행됩니다.

다만 사이트 이용 통계와 광고 게재를 위해 Google Analytics와 Google AdSense가 사용될 수 있습니다. 개인 사진은 분석 목적으로 서버에 보내지지 않지만, 일반적인 웹사이트 접속 정보와 광고 관련 쿠키는 Google 서비스 정책의 영향을 받을 수 있습니다.

## 사용 기술

- MediaPipe Face Landmarker: 얼굴 랜드마크 분석
- face-api.js: 보조적인 나이 추정
- html2canvas: 결과 카드 이미지 생성
- GSAP, Tone.js: 결과 공개 애니메이션과 효과음
- GitHub Pages: 정적 사이트 배포

## 이런 사람에게 추천

친구들과 가볍게 결과를 공유할 만한 얼굴 분석 테스트를 찾는 사람, 내가 어떤 부자 이미지와 닮았는지 궁금한 사람, 또는 브라우저만으로 AI 얼굴 분석 앱이 어떻게 동작하는지 보고 싶은 사람에게 잘 맞습니다.

결과는 어디까지나 재미로 보는 참고용입니다. 진지한 판단보다 "나는 어떤 타입으로 나오나"를 확인하는 쪽에 가깝습니다.

## 자주 묻는 질문

**부자 관상 테스트는 무료인가요?**

네. 별도 가입 없이 브라우저에서 바로 사용할 수 있습니다.

**내 사진이 서버에 저장되나요?**

아니요. 얼굴 분석은 사용자의 브라우저 안에서 실행되며, 테스트 사이트가 사진을 저장할 서버를 운영하지 않습니다.

**결과가 실제 재산이나 성공 가능성을 의미하나요?**

아니요. 결과는 얼굴 특징의 유사도를 재미로 비교한 것이며, 실제 재산이나 성공 가능성과는 관련이 없습니다.
